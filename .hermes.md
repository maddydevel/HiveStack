# HiveStack — Project Context (for Hermes agents and developers)

## Overview

HiveStack: KVM-based virtualization appliance on SUSE SLES 15 SP7. VMware migration target with multi-tenant hosting and SAP HANA support.

**Module:** `github.com/maddydevel/HiveStack`
**Go:** 1.26.0
**Root:** `/tmp/HiveStack`

## Build & Verification

```bash
go build ./...       # All packages
go vet ./...         # Static analysis
go test ./...        # Integration tests in tests/
```

**Must pass before committing.** Build and vet gates are mandatory.

## Architecture

- **Manager** (`cmd/hive-manager/`): Control plane — REST API, CLI, auth, RBAC, PostgreSQL (pgx/v5), events, compliance
- **Node Agent** (`node/`): KVM/QEMU/libvirt, gRPC server
- **CLI** (`cmd/hive/`): cobra CLI, table/JSON/YAML output

## Key Packages

| Package | Purpose |
|---------|---------|
| `internal/api/` | REST API server (stdlib ServeMux) |
| `internal/auth/` | JWT + Argon2id, RBAC engine |
| `internal/compliance/` | HANA guardrails, evidence chain, drift detection |

| `internal/manager/` | Manager core services, VM lifecycle |

## Conventions

- Context-first: all methods accept `context.Context`
- Thread-safe: `sync.Mutex` on shared state
- Stdlib `net/http` ServeMux (no framework)
- `log.Printf`/`log.Println` for logging
- No external deps beyond go.mod

## HANA Compliance

Guardrails: NUMA pinning, hugepages, dedicated vCPUs, no ballooning, no swap. Dual enforcement (Manager API + Node Agent libvirt XML). Evidence hash-chained (SHA-256) in `compliance_evidence` table. Drift detection publishes `compliance_drift_detected` events.
